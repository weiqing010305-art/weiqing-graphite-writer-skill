# 石墨极简排版效果示例

> 让重点清楚，让阅读留有呼吸。

这是一份排版示例，不是待发布的正式文章。

## 用层级组织阅读

黑白灰构成基础色调，细线划分章节，留白安排阅读节奏。正文默认使用 15px 字号，标题、编号和辅助标签形成清楚的层级。

章节不会为了凑数量而生成。排版已有稿件时，保留原有结构；没有引言或结语，就省略对应组件。

## 让强调有分寸

关键词用石墨下划线标记。优先突出观点、结论或关键概念，让读者扫读时知道这一段讲什么；过渡段可以保持干净。

暖橙只在少量关键位置出现。这份示例把它用在下一条提醒中，其余内容保持灰阶。

## 从正文到可复制预览

源稿、正文 HTML 和预览页承担不同用途。源稿方便修改，正文片段用于公众号，预览页负责显示效果并复制富文本。

下面展示代码组件。代码的引号、比较符号和缩进保持各自的含义，原始可执行文本保存在 Markdown 中。

if width < 375:
